# Holiday Mascots

Drop holiday-themed quail mascot PNGs here.

Naming convention: descriptive lowercase with hyphens, e.g.
- `santa-quail.png`
- `valentine-quail.png`
- `fireworks-quail.png`
- `thanksgiving-quail.png`
- `easter-quail.png`

These images are referenced by the holiday mascot system and can be
assigned date ranges via the Mascot & branding editor in the admin panel.
