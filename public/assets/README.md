# Branding assets

Drop your park-specific images here and they appear automatically across the app.

| File | Where it shows | Recommended size |
| --- | --- | --- |
| `logo.png` | Navbar (top-left) and login screen | square, 256×256+ (transparent PNG) |
| `mascot.png` | Login screen, empty-state fallback | square, 512×512+ (transparent PNG) |

Scene illustrations (optional) go in **`mascot/`** — see `mascot/README.md`.

Until these files exist, the UI shows clean text/emoji placeholders so nothing
breaks. No code changes are needed — just add the files with these exact names.
